# 📁 Panduan Foto LumiGlow

Satu folder per section/halaman. Drop foto dengan nama yang sesuai — langsung tampil.
Selama foto belum ada, otomatis pakai placeholder Unsplash.

|----------------------|----------------|---------------------|--------------------------------------------------------|
| `HomePage.tsx`       | Hero           | `home/`             | `bg.jpg`                                               |
